# Behavioral: STAR Method (Technical Failure)
# Link: https://github.com/donnemartin/system-design-primer#behavioral

## Context
Failure is inevitable in engineering. High-TC roles value candidates who can objectively analyze failures and lead corrective action.

## Questions (Response Required)
1. Using the STAR method, describe a specific technical project where something failed significantly.
2. What was the root cause (e.g., technical debt, miscommunication, architecture oversight)?
3. How did you communicate this to stakeholders?
4. What specific process changes were implemented because of this?
